Commands

  • zInteractive session, like Claude Code
  • z -p "…" --output jsonHeadless, for scripts and CI
  • z -c · z --resumeContinue or pick a past session
  • z topLive dashboard of every agent
  • z run weekly-vuln-triageStart a playbook
  • z review · z approve <id>Decide on pending writes
  • z logs <mission> -fStream activity
  • z usage --by agent --since 7dToken consumption
  • z connectors test logosCheck a connector
  • z mcp serveExpose Z as an MCP server
