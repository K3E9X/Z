# EBIOS RM study request: mobile messaging (fixture)

The study perimeter is still to be decided between:

A. the SMS gateway (SMSC and the A2P SMS API used by business customers to send one-time codes);
B. the MMS relay and its content adaptation platform.

Both run in the mobile core data centre. The A2P SMS API is exposed to about 300 business customers over the
internet. The MMS relay is only reachable from the mobile packet core.
